下载安装步骤：
1. git clone https://github.com/openJiuwen-ai/jiuwenswarm.git
2. cd jiuwenswarm
3. uv venv
4. uv pip install -e .
5. source .venv/bin/activate
6. jiuwenswarm-init（运行该命令，会有一系列选项配置，比如语言等）
7. cd /Users/xinchuangwulian/Desktop/myspace/code/jiuwenswarm/jiuwenswarm/channels/web/frontend
8. npm install
9. npm run build
10. jiuwenswarm-start

然后就可以访问http://localhost:6173
